# Profile cards

The README is a stack of self-contained SVG images generated by one script,
`scripts/render_cards.py`. Links wrap the images in the README because links
inside an SVG cannot be clicked when it is displayed as an image.

## Render and screenshot

Use Python 3.10 or newer:

```sh
python3.12 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/render_cards.py
```

Create a separate final-frame preview, leaving the animated cards ready to commit:

```sh
STATIC=1 python scripts/render_cards.py --output preview --preview
python -m http.server 8000
```

Open <http://localhost:8000/preview/> and take a screenshot. `preview/` is ignored
by Git. The preview uses actual `img` elements, including the three tiles in one
row at 32.5% each. It follows the browser's light/dark theme. For an animated
preview, omit `STATIC=1`. `STATIC=1` removes CSS keyframes and SMIL animations,
uses full-height bars, and sets every line to its final state. The default output
is `cards/`; use `--output preview` to keep a static screenshot copy separate.

An optional portrait is embedded in the hero with no external image request:

```sh
python scripts/render_cards.py --portrait /path/to/portrait.png
```

PNG and JPEG are supported. To keep a portrait in daily builds, commit it under
`assets/` and add the same `--portrait assets/portrait.png` argument to the workflow's
render step. The default hero uses a restrained animated divider.

## Brand and content

The design was derived from [Ujjwal's website](https://sharma-ujjwal.vercel.app)
and its deployed stylesheet on 10 November 2026:

| Token | Light | Dark |
| --- | --- | --- |
| Background | `#fefcf8` | `#1c1917` |
| Text | `#1c1917` | `#ededed` |
| Sage accent | `#89937a` | `#9da591` |
| Secondary text | `#57534e` | `#a8a29e` |

Headings and body copy use **TASA Explorer**, with **Oxygen Mono** for technical
metadata and chart labels. Both are taken from the website; the exact TTF files
served by the website are vendored in
`assets/fonts/`, together with their SIL Open Font Licenses. The renderer runs
**pyftsubset** on the characters used by each font in each card and embeds the
result as a base64 WOFF data URI. A normal build needs no network or system fonts.
The layout uses a consistent type hierarchy, compact repository cards, and a
four-column activity summary. Animations use short entrances and settle once.

Source font URLs:

- <https://sharma-ujjwal.vercel.app/_next/static/media/TASAExplorer_VariableFont_wght-s.p.04fg5tbrnjfgf.ttf>
- <https://sharma-ujjwal.vercel.app/_next/static/media/OxygenMono_Regular-s.p.0dvtrdn1qis4j.ttf>

Edit `data/profile.json` for copy, tile destinations, and featured repositories.
When adding/removing a card, update its linked `img` in `README.md` too. The five
featured repositories come from the previous README; RouteX's description was
checked against its repository metadata. The previous README, including all

## Data and daily updates

`.github/workflows/snake.yml` runs daily at **00:00 UTC / 05:30 IST**, or manually
with **Run workflow**. It installs the pinned subsetter, runs the checks, refreshes
`data/contributions.json`, renders animated cards, retains the existing snake
generation, and commits only the contribution JSON, SVG cards, and snake SVGs.
Its `GITHUB_TOKEN` uses the repository's `contents: write` permission for the
commit. No personal access token is needed.

The script queries GitHub's official GraphQL contribution calendar for the last
365 days through the refresh date. The JSON records its username, source, fetch
time, and contiguous daily counts. API errors or missing days fail the action
without replacing the last valid snapshot. Rendering always reads this saved
file, so a network failure never becomes invented activity.

To refresh locally with an authenticated GitHub CLI:

```sh
GH_TOKEN="$(gh auth token)" python scripts/render_cards.py --refresh
```

The monthly chart includes every calendar month touched by the snapshot; its
edge months can be partial. All totals use the same window. An active day has at
least one contribution. The current streak ends on the snapshot's last day, or
the day before it if the last day is still zero. The longest streak is within
the saved window. Tied busiest days use the most recent date. A calendar with
no activity displays zeroes and “No activity yet”. Counts reflect the GitHub
calendar visible to the workflow token; private contribution visibility follows
the account's GitHub settings.

## Image compatibility and motion

Cards contain SVG shapes, text, one inline style block, embedded fonts, CSS
keyframes, and SMIL `animate` elements. There are no scripts, `foreignObject`,
remote resources, hover dependencies, or external stylesheets. Titles,
descriptions, and README alt text provide text alternatives.

Entrance delays increase from hero to tiles, chart, repositories, and graph;
animations play once and settle. Under `prefers-reduced-motion: reduce`, CSS
animations and transitions are disabled and `!important` final-state styles
override SMIL stroke values. These rules must target the animated shapes:
`animation: none` alone does not stop SMIL. Independent image loads can affect
the exact ordering; SVG images cannot coordinate their clocks with each other.

Run the regression checks with:

```sh
python -m unittest discover -s tests -v
```
